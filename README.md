# Japanese Humanizer

日本語の文章を、意味・事実・書き手の声を保ったまま、自然で読みやすい形へ整えるAIエージェント用Skillです。

メール、記事、企画書、レポート、議事録、説明文などに使えます。単語を機械的に置き換えるのではなく、読者と用途に合わせて語順、文の区切り、段落、文末を調整します。

## 特徴

- 日本語特有の語順、文末、読点、翻訳調を確認
- 元文の事実、数値、固有名詞、引用を保持
- 書き手本人の語調を優先
- 過剰な小見出し、反復、誇張などを文脈に応じて整理
- 外部モデル、外部API、実行スクリプトへの依存なし
- AI生成判定の回避を保証しない

## インストール

### Codexのリポジトリ専用Skillとして使う

利用するリポジトリ内へ、次の配置で`SKILL.md`を保存します。

```text
.agents/
└── skills/
    └── japanese-humanizer/
        └── SKILL.md
```

このリポジトリをそのまま取得した場合は、ルートの`SKILL.md`を上記の場所へコピーしてください。

### ファイルをAIへ渡して使う

`SKILL.md`を添付し、次のように依頼します。

```text
添付したSKILL.mdを、日本語文章を推敲するときのSkillとして使用してください。
元の事実と書き手の語調を保ち、自然な日本語へ整えてください。
```

利用しているAIハーネスがリポジトリSkillに対応していない場合も、`SKILL.md`を作業時の指示資料として渡せます。

## 使用例

```text
この企画書をjapanese-humanizerで整えてください。
内容は増やさず、ユーザー本人が書いた自然な文体を残してください。
```

```text
次のメールを自然な敬語へ直してください。
日付、金額、固有名詞は変更しないでください。
```

```text
書き換えずに、AIっぽく見えやすい箇所だけ診断してください。
```

## 対象外

- 引用や法的文言を一字一句そのまま扱うだけの作業
- コード、コマンド、URL、識別子の書き換え
- 元文にない事実や具体例の追加
- AI生成判定を確実に回避するための利用

## ファイル構成

```text
.
├── SKILL.md
├── README.md
├── LICENSE
└── .gitignore
```

このSkillは`SKILL.md`だけで動作し、追加パッケージやネットワーク接続を必要としません。

## 更新内容（1.2.0）

- 意味に役立つ反復、多義性、話し言葉、省略を、機械的に削らない判断基準を追加
- 言い換えの前後で、意味だけでなくリズムや区切りも比較する方針を追加
- コピーや短い呼びかけと、正確さを優先する説明・手順などで適用を分ける方針を明確化

公開版は引き続き単独で使える指示のみのSkillです。別Skillへの必須依存、個人設定、ローカル専用のlintスクリプトは含みません。ローカル版の完全なコピーではありません。

## 更新内容（1.1.0）

- 主語・対象・修飾先を確認し、条件・否定・例外・数量を保つ点検を追加
- 比喩や接続詞から、元文にない原因や因果関係を補わない方針を明確化
- 答えを先に置く説明と番号付きの操作手順を追加し、指定書式や必要な情報量は維持
- 校正対象の命令と、実際の操作権限・承認を分離
